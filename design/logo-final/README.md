# 街研品牌标

最终方向：C「扫描视角」。

标识由三部分组成：未闭合的观察环、中心观察点，以及向右下延伸的橙色检索手柄。它同时表达街区观察与主动调研，不直接描画地图或放大镜素材。

## 文件

- `streetbrief-scan.svg`：彩色主标
- `streetbrief-scan-small.svg`：小尺寸加粗版本
- `variants/streetbrief-scan-black.svg`：单色黑
- `variants/streetbrief-scan-white.svg`：深色背景反白
- `variants/streetbrief-scan-square.svg`：方形社交头像
- `variants/streetbrief-scan-favicon.svg`：网页图标

主色为 Ink `#152a30`，强调色为 Signal Coral `#df6246`。字号、间距和反白效果仍需在实际网页与打印机中做最终介质确认。
